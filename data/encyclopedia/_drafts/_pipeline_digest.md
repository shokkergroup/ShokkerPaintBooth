# Pipeline digest: how SPB composes paint + spec (code facts, 2026-10-04)
Files: E = shokker_engine_v2.py, C = engine/compose.py, O = engine/overlay.py, K = engine/core.py (all project root). Lines are as of this date. UNVERIFIED = not confirmed in code.

## 0. Constants and unit facts
- Spec map: R=Metallic, G=Roughness, B=Clearcoat, A=spec mask (E:23-27 docstring). Canvas size is whatever the input paint is: `h,w = scheme.shape[:2]` (E:18102). A 2048 requirement is not enforced inside the engine (UNVERIFIED upstream in server.py).
- CC_FLOOR=16 (E:267). ROUGHNESS_FLOOR_NONMIRROR=15 (E:270). CHROME_M_THRESHOLD=240 (E:274). Same values as SPEC_CLEARCOAT_MIN=16, SPEC_ROUGHNESS_MIN=15, SPEC_METALLIC_CHROME_THRESHOLD=240 (K:72-74).
- Default spec before any zone: M=5, R=100, CC=16, A=255 (E:18494-18505; K:77-78 "outside zone" M=5,R=100). Imported spec map replaces this start state (E:18472-18497).
- Intensity (zone "intensity", 0-100) -> sm/pm/bb = pct * (2.00 spec, 1.50 paint, 0.15 bright) (K:884-888; E:21157 `_parse_intensity`; E:18758-18777 custom_intensity uses the same scale). Pattern intensity: `pattern_intensity` -> sm_pattern (E:18779-18787).
- Compose clamps: scale 0.01-10, strength 0-2 (C:281-283, C:2868-2880); overlay strength 0-1, overlay scale 0.01-5 (O:41-44).

## 1. build_multi_zone, in execution order (E:17864 def)
1. Validate zones + render ids (E:17945, E:17999). Writes `_audit/last_render_trace.json` + rolling history of the recipe every render (E:17953-17995).
2. Export only: writes `zones_payload.json` (E:18018-18030); backs up source as `ORIGINAL_<name>` next to it and always re-loads from that backup (E:18037-18058). Preview skips both.
3. Load paint to float 0..1 (E:18062-18105). Colour stats (HSV/luma) computed only if some zone selector needs them (E:18108-18131).
4. Zone mask pass 1, for each zone in array order (E:18161-18343). Per zone, one of:
   - Drawn region ("region_mask"/apply-area): the drawn shape REPLACES colour matching; it is multiplied by the colour mask only if `_zone_apply_area_intersects_color` (E:18165-18203).
   - Colour match: single selector, list (union via max), or dict, via cached `_build_color_mask_from_desc` (E:18211-18297). If the zone has `source_layer_rgb`, matching runs on that layer's own pixels with alpha<8 rejected (E:18218-18267).
   - Feather: Gaussian blur 3 px, or 0 when `hard_edge` (hard_edge = zone flag or has source_layer_mask) (E:1520-1528; `_blur = 0 if hard_edge else 3` inside E:18161-18297).
   - Include/exclude "spatial_mask": value 2 zeroes the mask; if any pixel is 1, the mask is kept only on those pixels (E:18303-18321).
   - PSD layer restriction: mask * source-layer alpha, flagged `_spb_zone_mask_source_layer_gated` (E:18323-18330).
   - `color:"remaining"` zones are deferred as None placeholders (E:18238-18250, 18267-18275).
5. Overlap pass 1: `mask = clip(mask - claimed*0.8, 0, 1)`; then `claimed += mask` clipped to 1 (E:18200, E:18336-18340). EARLIER zone claims first; lower index wins.
6. Harden: `HARD_THRESHOLD=0.15`; soft mask above 0.15 becomes 1.0, below it is `m*m/0.15`; hard_edge zones become binary (>0.01 -> 1) (E:18353-18372).
7. Optional `priority_override` (needs an include spatial_mask): that zone's pre-claim mask beats earlier zones, and later override zones are subtracted from earlier ones (E:18374-18396, 18456-18470, 18560-18576).
8. Remainder zones: `1 - claimed_hard`, Gaussian sigma 2.0 (0 for hard_edge), pixels with claimed_hard>0.5 set to 0 (E:18408-18448; E:1853-1862). Source-layer remainders resolve only inside their own layer (E:1864+).
9. `prior_claimed[i]` = running union (clipped to 1) of all earlier zones' hardened masks (E:18450-18457).
10. Per-zone render mask at loop time: `zone_mask = zone_mask_raw * (1 - prior_claimed[i])` (E:18563), so an earlier zone always wins overlaps; then later priority-override zones are cut out (E:18566-18568); then source-layer mask (E:18570-18581); then, for source-layer zones, a final `zone_mask >= 0.5` binarisation (E:18583-18586). Zones whose mask max<0.01 are skipped (E:18592-18594). Docstring states "FIRST WINS" (E:17868-17871).
11. Zone cache: key = paint hash + seed+13*i + preview flag + all zone settings + mask digest (E:18597-18651). A hit replays cached spec/paint and does its own hard/soft spec composite inline (E:18651-18738); cache holds max 24 entries (E:18917, 20290). Cache stores the spec AFTER sliders/remap/override (E:20257).
12. Seeds: each zone renders with `seed + i*13` (compose calls e.g. E:19380-19400; overlay lane offsets +999/+2999/+3999 inside compose_finish).
13. Dispatch (E:18790-18817): `mono:` prefix and "finish that is really a base" are normalised to base_id/finish_name. Exactly one path runs:
    - PATH 0 custom mix (`base` starts "custom_"): `mix_finishes` for spec and `mix_finish_paint` for paint using custom_finishes.json weights, mix_mode both/color/spec; applies remap/override/lighting then composites and `continue`s, so PATH 0 SKIPS the post-path steps 19-22 below (spec placement, pattern-less physical blend, pattern spec amount, spec channel sliders) and the zone cache store (E:18819-18927).
    - PATH ZSPEC: zone has only an imported spec map (`zone_spec_map`), no base/finish: spec = that map blended by `zone_spec_map_strength` (E:18943-18949, 1274-1306; strength E:464-468). Paint untouched.
    - material_stack ("Whole Car" stack): Spec Sculpt compositor makes M/R/Cc only, paint untouched; `material_stack_amount<1` pulls M/R/Cc toward neutral (0,160,255) (E:18951-19007).
    - PATH 1 compositing (`base` in BASE_REGISTRY): `compose_finish` (spec) runs in a thread while `compose_paint_mod` (paint) runs in the foreground; with a pattern stack it uses the `_stacked` twins (E:19010-19480, 19305-19380).
    - Fast paths for PATH 1: flat no-op bases get a constant spec plate; sparse zones use a bounding-box crop path (E:19417-19466; E:561, 1195).
    - PATH 2 monolithic (`finish` in MONOLITHIC_REGISTRY, ~846 finishes): spec_fn + paint_fn (E:19506-20109).
    - PATH 3 legacy FINISH_REGISTRY (E:20111-20125). PATH 4 generic client "finish_colors" (E:20127-20143). Gradient-named finishes with finish_colors (grad_, gradm_, grad3_, ghostg_, mc_) go to a gradient renderer (E:19481-19505).
    - No match: warning and the zone is skipped (E:20145-20152).
14. PATH 1 spec side, `compose_finish` (C:2808-3946), in order:
    a. Base spec: base_spec_fn, brush_grain, perlin, noise_scales, or flat M/R (C:2922-2965). Noise amplitude scaled by `_sm_base = sm * base_spec_strength` (C:2903).
    b. Spec Strength: `_scale_base_spec_channels_toward_neutral` when strength not within 0.999-1.001 (C:2967-2970; def C:428-438). See section 2.
    c. Base scale/offset/rotation/flip (C:2972-2977, 3071-3106). `cc_quality` rewrites CC to `16 + (1-q)*239` (or `(1-q)*90` if base CC is 0) (C:2986-2994). `blend_base` two-base gradient (C:2996-3055). `paint_color` (C:3056).
    d. Primary spec-pattern stack (legacy v1 layers): per layer the pattern array is added to selected channels M/R/C with range (default 60) * opacity and a blend mode normal/multiply/screen/overlay/hardlight/softlight (C:3108-3188; C:2551-2600, 2713-2806). CC gets a polarise + 2.5x gain and a floor of 16 (C:2779-2800). Legacy layer opacity is sqrt-curved (contract.py:29-34).
    e. Pattern spec: `pattern_sm_eff = pattern_sm * sqrt(pattern_intensity)` (C:2886-2888); added as `M += M_pv*M_range*pat_scale`, `R += R_pv*R_range*pat_scale` where `pat_scale = pattern_sm_eff * spec_mult * pattern_opacity` (C:3190-3346). Physical modes (ghost_carve, chrome_inlay, frost_etch, angle_flip, ember_gate, depth_press) rewrite all three channels instead (C:2619-2622, 3216-3321). Skipped when `pattern_spec_opacity` exists in the zone ("independent pattern spec", C:3190).
    f. Zone-mask assembly: `M = M*mask + 5*(1-mask)`, `R = R*mask + 100*(1-mask)`, R floored 15 where M<240 (`_ggx_safe_R`, C:400-420, 3347-3400); CC floored to 16 where mask>0.5, multiplied by mask; A=255 (C:3358-3401). Final in-function guard: R>=15 non-chrome, CC>=16 everywhere (C:3925-3933).
    g. Overlay bases 2nd, 3rd, 4th, 5th: each blends a second spec through `blend_dual_base_spec` with its own strength, spec strength, blend mode, noise scale (C:3475, 3554, 3643, 3720; O:534). Overlay blend modes (canonical): dust, marble, pattern, pattern_vivid, tint, pattern_edges, pattern_peaks, pattern_glow, pattern_fresnel, pattern_flow, pattern_shatter; unknown -> dust (O:133-157, 251-470). Overlay alpha is linear in strength, 0 gives the primary only (O:211-232).
    h. Overlay spec-pattern stacks per overlay lane (C:3797-3920). Then versioned (v2) spec overlays are applied last on the completed material, as a convex mix `current + (target-current)*coverage*strength`, M/R/Cc, Cc=0 allowed (C:3944; spec_overlay_v2/compose.py:10-57; contract.py:47-70).
15. PATH 1 paint side, `compose_paint_mod` (C:4982-5820), in order:
    a. Snapshot source paint (C:5036); `hard_mask = mask where mask>0.1` (C:5040).
    b. Base Strength constants: RAW=clamp(s,0,2); MIX=min(1,RAW); BOOST=max(1,RAW) (C:5055-5057).
    c. Base paint_fn (pm*BOOST, bb*BOOST) runs ONLY if the base has a paint_fn and base_color_mode is NOT source/none (`_source_paint_lock`, C:5135-5170). In source mode the base contributes spec only and the car's own paint is untouched.
    d. Base colour override `_apply_base_color_override` (C:2218-2500), modes: source/none/finish (no-op), solid, gradient, special/from_special/mono (C:2243-2246, 2372, 2418); strength 0-1; optional depth/flip/underglow ("Color Lab"); placement scale/offset/rotation/flip.
    e. HSB: hue +-180 deg rotate; saturation `s*(1+adj/100)`; brightness `v*(1+adj/100)`; both clipped 0..1; skipped if all three |x|<0.5; applied only inside the mask (C:1799-1850, 5188-5193).
    f. Base-scale placement of the paint, no-op in source mode (C:5211-5238). `blend_base` paint gradient (C:5239-5284).
    g. BASE STRENGTH mix: `out = source*(1-a) + result*a`, `a = mask * MIX` (C:4966-4979, 5287-5291). Patterns come AFTER this, so Base Strength does not dim them.
    h. Pattern paint: `_pi = sqrt(pattern_intensity)` (C:5294). paint_mode overlay/blend uses `composite_pattern_pixels` with `amount = pattern_intensity * clip(spec_mult,0,1)`; `legacy` mode alpha-composites with `alpha*_pi` (C:5295-5330; pattern_paint_placement.py:51-77). "blend" keeps source hue/sat and sets value to `0.2*V + 0.8*(0.1+0.85*detail)` (pattern_paint_placement.py:59-68). Pattern hue shift (degrees) and saturation (-100..100) apply to the pattern only.
    i. Overlay bases 2nd-5th, after the pattern, in that order: alpha from `get_base_overlay_alpha`, then `paint*(1-a) + overlay*a`; own HSB per overlay (C:5426, 5549, 5642, 5731).
16. Pattern stack (up to 4 extra patterns after the primary): each has opacity, scale, rotation, hue/sat, blend_mode, fit_zone; auto-scale applied to each (E:19305-19332; `compose_finish_stacked` C:3949, `compose_paint_mod_stacked` C:5823).
17. Auto-scale: `area_ratio = bbox_area/canvas`; scale 1.0 if >0.6 else `clamp(sqrt(ratio), 0.15, 1)` (K:1498-1527; used E:19027, 19514). Fit-to-zone replaces it (E:19028-19042).
18. PATH 2 monolithic order (E:19506-20109): render the finish's spec_fn and paint_fn over the zone mask with `sm * base_spec_strength` (authored/SHOKK DROP imports use sm=1.0 and ignore the slider, E:19549); finer-scale tiling; base-colour override unless mode is source/finish/own (E:19930-19965); HSB (E:19967-19974); `_blend_monolithic_base_strength` = `under*(1-a)+mono*a`, `a=mask*min(1,s)` (E:17773-17790, 19976); single pattern overlay (E:19980-19984); pattern stack up to 4 (E:19985-20003); spec_pattern_stack (E:20005-20097); overlay bases 2nd-5th (E:20103-20109). Monolithic paint is always rendered at full colour; Base Strength is the only paint blend, and zone intensity no longer scales paint colour (E:19558-19586).
19. Post-path, common to PATH 1-4 (not PATH 0): imported zone spec blended in if present (E:20153-20154); spec placement post-pass (scale/offset/rotation/flip of the spec only) (E:20156-20169).
20. Pattern-less PHYSICAL spec blend: if `base_spec_blend_mode` is a physical mode and the zone has no pattern, the field is the zone's rendered paint luminance, else the base's spec geometry (0.6*CC+0.4*M), else flat 0.5; floors inside it: R>=15, CC>=16 (E:20170-20219).
21. Pattern spec amount (`apply_zone_pattern_spec`): per pattern `spec = spec*(1-amt) + plate*amt` on M/R/C, amt=`pattern_spec_opacity`/layer `spec_opacity` clipped 0..1, alpha untouched; plate is the pattern compiled onto a full-mask chrome base (pattern_material.py:11-79; E:20221-20223). Only runs if the key `pattern_spec_opacity` exists in the zone. Such zones are marked `_pattern_spec_preserve` and are EXEMPT from the final R and CC floors (E:18609-18610, 20733-20742).
22. SPEC CHANNEL SLIDERS `spec_channel_shift` {r,g,b}: add `shift * mask` to M, R, CC; clip per channel to floors 0, 15, 16 and ceiling 255; ignored if all |shift|<=0.5; documented range -127..+127 (E:20225-20250). Runs after patterns/overlays/blend modes.
23. Spec material tools, in this order (E:20253-20255): `spec_material_remap` (per-channel Levels low/high on M,R,CC: `low + v/255*(high-low)`, E:366-393), `spec_material_override` (flat M,R,CC,A values, E:396-420), `spec_lighting_mask` (replaces A with 0-255, E:331-355). These run before the final floors, so a flat override of R<15 on a non-chrome pixel or CC 1-15 is lifted by the floors in step 29 (unless the pixel is preserved).
24. Store in zone cache (E:20257-20294). Optional per-zone layer capture for export_layers (E:20296-20315).
25. Composite zone spec into `combined_spec` (E:20317-20366). hard_edge zones: `where(mask>=0.5, zone_spec, existing)`. Soft zones: mask>0.5 replaces all four channels, 0.05<mask<=0.5 linear blend, <=0.05 untouched. Authored (SHOKK DROP) specs mark their pixels as CC-floor-exempt where mask>0.5 (E:20368-20380). Paint is composited inside compose_paint_mod (linear by mask, mask<=0.1 ignored), not here.
26. Post-loop: DECAL RGB PROTECTION restores source RGB where the client decal mask is on, so overlays and bases cannot repaint numbers/sponsors (E:20387-20432). Runs before wear.
27. Wear: one `apply_wear` pass at the max wear level, blended per zone by `wear_level/max` only where zone_mask>0.5 (E:20434-20470; apply_wear re-applies `_enforce_iron_rules`, E:22932, 23010).
28. Decal spec finishes (one finish for all decals): flat M/R/CC plates blended by decal alpha over all four channels, e.g. gloss 0/20/16, matte 0/220/200, satin 0/100/50, satin_metal 235/65/16; f_* ids use the base's own M/R/CC (E:20495-20653). Spec stamps: same blend with the stamp alpha, finishes gloss/matte/satin/satin_metal/metallic/pearl/chrome; stamp RGB also pasted into paint (E:20655-20727).
29. Final iron rules, inline in build_multi_zone (NOT via `_enforce_iron_rules`; that helper at E:301-327 is used for imported-spec blends E:1295-1306 and wear, not here):
    - Roughness: `R = max(R, 15)` where `M < 240` and the pixel is not `_pattern_spec_preserve` (E:20735-20737).
    - Clearcoat: `CC = max(CC, 16)` EVERYWHERE (including CC=0 matte) except `_authored_cc_preserve | _pattern_spec_preserve` pixels, which keep their value (E:20738-20744). The helper `_enforce_iron_rules` would instead keep CC==0 as 0 (E:323-326); the build path does not.
    - NaN/Inf -> 0/255, clip 0..255, cast uint8 (E:20745-20747). Paint = clip(0..1)*255 uint8, alpha dropped (E:20729-20731).
    - Alpha: starts 255 everywhere; changed only by lighting mask / override / imported spec alpha. The docstring claim "alpha is the union of zone masks" (E:35-37) is NOT implemented in this function; the only code max-union of alpha is for imported spec maps (`np.maximum` at E:1305).
    - Material instances applied after the floors (E:20753-20757).
30. Export outputs (E:20772-20828): paint `car_num_<id>.tga` (or `<car_prefix>_<id>.tga`) via `write_tga_24bit`; spec `car_spec_<id>.tga` via `write_tga_32bit` (RGBA, written as BGRA, header 0x28, K:214-264, 266+); optional `_normal.tga` from Sobel on the M channel (E:20774-20795, ksize 3, 0.5+dx*0.5); `PREVIEW_paint.png`, `PREVIEW_spec.png` (E:20797-20799). Core docstrings in K:215 and K:267 mislabel 32-bit as "paint" and 24-bit as "spec"; the actual calls are as stated here.
31. Server export route calls `full_render_pipeline` (server.py:5856; E:23252) = build_matching_set (car + helmet + suit) then optional extra wear (global `wear_level` applied to the finished car spec/paint, helmet -20, suit -40, E:23334-23360), re-writing the TGAs, then optional zip.

## 2. Spec strength and base strength
- Spec Strength (`base_spec_strength`, 0-2, default 1): `M' = 0 + (M-0)*s`; `R' = 128 + (R-128)*s`; `CC' = 16 + (CC-16)*s` (C:428-438; neutral values M=0, R=128, CC=SPEC_CLEARCOAT_MIN=16). So s=0 gives a plain M=0, R=128, CC=16 plate (before floors); s>1 exaggerates and is clipped later. Applied to the base's spec before patterns and overlays (C:2967-2970; stacked twin C:4078). Monolithic/other paths use the same function as a post-pass (`_apply_base_spec_strength_to_zone_spec`, E:17488-17508; used E:19759, 19846, 19873). Authored imports skip it (E:19758).
- The same slider also scales noise amplitude of noisy bases (`_sm_base = sm*s`, C:2903) and the base's CC scalar (`_scale_base_clearcoat_scalar`, C:441-444, 2921); for noisy bases the effect is therefore stronger than the formula alone (UNVERIFIED numerically).
- Server maps both camelCase and snake_case: server.py:5096-5100.
- Base Strength (`base_strength`, 0-2) is paint only: spec is NOT affected (C:2902 comment). `mix = min(1,s)` blends the complete base result over source paint: `out = source*(1-mask*mix) + result*mask*mix` (C:4966-4979). Values above 1 only boost the base paint_fn input (BOOST, C:5057). Monolithic path: same formula (E:17773-17790).
- Zone Intensity (separate): sm = spec%*2.0 feeds spec generators; pm = paint%*1.5; bb = bright%*0.15 (K:884-888). Note intensity scales spec amplitude of bases, whereas Spec Strength pulls toward neutral.

## 3. surface_intent.py (engine/paint_v2/surface_intent.py, 225 lines)
- Pure lookup table: `CATEGORY_INTENT` maps category name -> spec_driven / pattern_design / pattern_image / fine_structural_color / full (surface_intent.py:98-160; default FULL via `get_intent`, `is_spec_driven`, etc., near the end). spec_driven = Foundation, Clearcoat, Ghost Geometry; Foundation EFX is FULL; fine_structural_color = Cryptid/Morpho/Bloom/Petri, Neon, ASTRA; per-finish override only `pattern:tribal_celtic_spiral` -> pattern_image.
- VERIFIED: nothing in shokker_engine_v2.py, engine/compose.py, engine/*.py or server.py imports it. The render never reads intent; the same dispatch above runs for every finish.
- Consumers are QA and tooling only: M6 metric (scripts/spb_workbook_compute_m6.py:275), M7 composite weights (scripts/spb_workbook_compute_m7.py:56-60: spec_driven weights m2 0.20, m5 0.30, m6 0.50 and M1/clone penalty skipped at m7:147-158; pattern_design m1 0.30, m5 0.20, m6 0.50; fine_structural_color m5 0.375, m6 0.625), audit scripts (audit_spec_driven_*), and thumbnail bake (scripts/bake_spec_driven_thumbnails.py:139-162 renders the SPEC channel as the thumbnail for spec_driven categories).
- Spec-driven behaviour comes from data, not intent: Foundation bases (f_*) are BASE_REGISTRY entries with `paint_fn: paint_none` and a flat M/R/CC, e.g. f_chrome M255 R2 CC16, f_satin_chrome 250/45/40, f_metallic 200/50/16, f_soft_matte 0/200/165, f_clear_satin 0/100/75, f_soft_gloss 0/42/22 (engine/base_registry_data.py). With base_color_mode "source" the paint is skipped (C:5135) so only spec changes.

## 4. Preview versus export
- Same function: `preview_render` (E:20879) calls `build_multi_zone(preview_mode=True, output_dir=None)` (E:21027-21037), so zone masks, paths, floors, wear, decal protection, decal spec and stamps run identically; docstring claims preview matches final (E:20885-20887).
- Differences found:
  1. Resolution: `preview_scale` clamped 0.05-1.0, default 0.25 in the engine (E:20879, clamp ~E:20910-20915); server default 0.25, min 0.0625, max 1.0 (server.py:138-140). Source paint is LANCZOS-resized to `int(orig*scale)` (min 16 px), cached by content hash (E:20962-20972); region/spatial masks resized NEAREST (E:21010-21020). At scale 1.0 the source is used as is.
  2. Floors: preview returns AFTER the same floor block (E:20729-20744 then `if preview_mode` E:20760-20763), so iron rules are identical.
  3. No file I/O: no zones_payload.json (E:18018), no ORIGINAL_ backup/redirect (E:18037), fast cached PNG load `_load_preview_source_rgb` (E:18062-18077, def E:17825), no TGA/normal map/PREVIEW PNGs/zone debug images (E:20772-20828). Returns `(paint_u8, spec_u8)` (plus layers if export_layers).
  4. Abort: `abort_event` makes preview return a partial render early with the same floors (E:18530-18541, 20484-20493).
  5. Zone-cache key includes the preview flag, so preview and export entries never mix (E:18647).
  6. Picker snapshots use `PICKER_SNAPSHOT_RENDER_SCALE=0.5` (server.py:2418, 2765).
  7. Export-only extras: `full_render_pipeline` global wear, helmet/suit, night/dual spec (E:23252+; server.py:5856).
- UNVERIFIED: whether pixel-based noise scales (octave sizes in px) are rescaled at preview_scale<1; compose receives `shape` only, so fine detail is likely not pixel-identical to 2048 export.
