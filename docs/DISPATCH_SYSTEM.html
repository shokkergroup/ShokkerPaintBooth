How a Tool Click Flows

1. USER ACTION
Mouse Down / Tool Button
onmousedown or toolbar click
2. DISPATCH
dispatch.js
Checks toolbarEditMode
3. DECISION
Zone or Layer Guard?
zoneOnlyToolNames
layerOnlyToolNames
ZONE PATH
→ requireZoneToolbarMode(toolName)
→ Tool operates on zones[selected].regionMask
→ Uses paintRegionCircle, spatial brushes, etc.
→ Undo: pushZoneUndo
LAYER PATH
→ requireLayerToolbarTarget(toolName)
→ Tool operates on active PSD layer pixels
→ Uses _initLayerPaintCanvas, layer undo
→ Undo: _pushLayerUndo
Autonomous Rule: Any change to routing logic must live in js/canvas/dispatch.js. Never add new if (isLayerToolbarMode()) checks anywhere else in the codebase.
