# Shokker Paint Booth 11.0.0 (beta) - V11

11.0.0 is the biggest update since launch. The app is now "Shokker Paint Booth V11"; it upgrades V10 in place (same settings and projects) and adds a new "Shokker Paint Booth V11" desktop shortcut.

- **More paint:** 170 new finishes - a second set of Fractured Cosmos (60) and Fractured Wilds (110), with the originals kept under FIRST SET. The Flames shelf was rebuilt into 20 distinct flame finishes and all 50 ASTRA finishes were rebuilt.
- **Car menu** (was Symmetry): Number Kit (doors + roof, turned to read right, fonts/outline/shadow/chrome/vinyl, replaces existing numbers at the same size and spot), Sponsor Kit (strips the white box, places logos at real size on the panels you pick, foil and vinyl looks, one-undo removal), Car Stripe, Car-Space Fade (fades along the car so both sides match), Race Wear Studio (Short-Track Oval, Road Course, Dirt Late Model, Endurance 24 h), plus the mirror tools.
- **Material / Spec menu:** Auto Spec suggests a material per layer with a Showroom-to-Race-Worn dial; Spec Doctor checks the spec map before you upload and only changes things when you press a fix button.
- **Editing:** a real Text tool, snapping guides when moving layers, gradient presets with editable colour stops, and a Special brush that paints a finish and its spec in one stroke.
- **A cleaner look:** calmer dark skin with one accent colour, line icons, panels you can drag to resize, bigger spec tiles, a layout that fits a 1100 px wide window, and an honest engine status dot (green good, amber checking, red tells you what to do).
- **Faster and fixed:** quicker small-zone renders; loading a flat TGA shows your car; named parts get clean edges; busy renders retry instead of failing; Training Wheels stays closed; Getting Started guide links work.
- **AI helper (work in progress):** answers how-to questions, makes simple changes to the car you have loaded and checks your iRacing setup - offline, no account. Optional Claude Desktop connection (early). Every change has an Undo.

Download size is about 7 GB because every finish is included. Existing users get 11.0.0 automatically on their next launch.
