## What was built
1. **`server_routes/encyclopedia_routes.py`** - `GET /api/encyclopedia/search?q=&k=` (k 1-8, default 4). A Python port of the offline helper's search (`js/spb-offline-answer.js` build/search/bestFaq: same documents = the hand-written domains listed in the v2 index + help pages, same stop words / synonyms / stems / typo fix / BM25F field weights / intent nudges). Returns compact `{id, title, summary, faq (the helper's best FAQ), more_faq (up to 2 more FAQs whose question is inside what was asked; model-only extra facts), how (3-4 steps), controls (<=4), sources (2), link "#enc:<id>", score, cov, confident}`; `confident` = the helper's own question bar (cov >= 0.34, score >= 2.4). k=4 worst case on the 30 questions 5.8k chars (about 1.45k tokens); the client sends at most 3. Hidden features: `scripts/ai_atlas/enc_hidden_features.json` (+ built-in Easy defaults when the file is not shipped) - hidden ids never indexed, hidden sentences scrubbed. Index built once (0.5 s cold), rebuilt only when a source file's mtime/size changes. Registered from `register_ai_copilot_routes` (no server.py edit).
2. **Online grounding** (`js/spb-pro-ai.js`, anchored edits only): `encWanted` (a question / how-to, not an edit, not a repair / picture turn) -> `encSearch` (2.5 s timeout, cached, runs in parallel with `warm()`) -> confident articles (<=3) become `SPB FACTS (authoritative ...)` + ANSWER RULES (answer from them, never contradict, copy labels / numbers, cite `(from "<title>")`, say so when not covered). They REPLACE the old `MANUAL EXCERPTS` for that turn (spb-ai-knowledge.js is kept; with no confident article the old excerpts are used as before). The reply gets `enc` (cited titles, else the top article) and the bubble shows **"Read the full article: <title>"** (opens `SpbEncyclopedia.open(id)`, fallback `#enc:<id>`). `get_help` (= MCP `spb_manual`) now returns `encyclopedia` first (+ `rule`), old manual cut to 2 excerpts.
3. **MCP**: new static tool **`spb_encyclopedia`** in `mcp/server/index.js` (read-only; GETs the server search directly, so it works with no paint / app page open; 404 -> "use spb_manual") + one INSTRUCTIONS line; `spb_manual` description in `mcp/server/tools.json` = the new in-app `get_help` description (minimal one-string edit, generator format kept).
