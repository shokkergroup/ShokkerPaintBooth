# Sliders and controls: what every zone setting does (AI knowledge card)

Machine-readable twin of this card: scripts/ai_atlas/app_controls.json (one entry per control with the exact zone field, range, default, interactions, evidence). Every control below is set with edit_zone / add_zone using the spec keys in brackets.

## Controls: colour (hue, saturation, brightness, solid colour, source paint)
BASE COLOR dropdown [color / gradient]: "Use finish's own color" (the material keeps its colour), "Use source paint (spec only)" (keep the car's colours, change only the shine: color "source"), "Use solid color" (an exact #rrggbb), "From special", "Custom gradient" (2-10 stops, direction horizontal / vertical / diagonal / radial). A plain solid colour renders exactly; never use the Color Lab (Depth / Flip / Underglow) for an exact colour. HUE SHIFT [hue -180..180] rotates every colour of the zone round the colour wheel (measured on green: +180 = magenta, -150 = hot pink, +150 = purple; shift = target hue minus current hue); SATURATION [saturation -100..100] greys out or boosts; BRIGHTNESS [brightness -100..200] darkens or lightens. They apply after the colour mode, on top of the finish's own or the source colours, and never change the shine. Greys have no hue: they need a colour mode, not a hue shift.

## Controls: base material (scale, rotation, strength, intensity)
BASE SCALE [scale 0.05-5x, 1 = normal]: smaller = finer flake / grain of the base material. BASE ROTATION [rotation]: direction of brushed or grain textures. BASE STRENGTH [base_strength 0-100%, UI] fades the whole finish over the car's own paint (0 = original paint, 100 = full finish). SPEC STRENGTH [spec_strength] weakens or boosts only the material (shine / metal) not the colour. INTENSITY [intensity 0-100] is the whole-zone strength preset: lower = calmer, closer to the original. WEAR [wear] scuffs the finish. Wrong control = no visible change: for "more subtle" use base strength or intensity, for "less shiny" use spec strength.

## Controls: pattern (id, scale, rotation, opacity, paint mode)
PATTERN swatch [pattern.id] paints a repeating design on the zone. PATTERN SCALE [pattern.scale, UI 0.1-4x]: a SMALLER number repeats the pattern MORE times = a finer weave, smaller scales, tighter camo; 0.5 is twice as fine and is what the owner means by "crushed to 50%"; the car is one 2048 sheet, so 1.0 often reads big. ROTATE [pattern.rotation 0-359]. OPACITY [pattern.opacity 0-100] fades the pattern into the base colour (30-50 = subtle). STRENGTH (pattern effect in paint and spec). PAINT MODE (measured: in Overlay a snake pattern paints its own brown and your base colour does not show): Overlay draws the pattern's own colours; Blend keeps the paint colour and only modulates light / dark with the pattern, so the base colour decides the camo hue. More pattern layers (up to 4 extra) each carry their own opacity, scale, rotation and blend; edit_zone sets pattern 1 only, use a second zone for another pattern.

## Controls: spec patterns (shine texture, never colour)
SPEC PATTERNS [spec_patterns: up to 5 layers, each {id, opacity, scale, rotation, channels}] change HOW the surface reflects: sparkle, brushed sheen, scale-by-scale highlights. Opacity (default 50) is the strength, Scale smaller = finer, channels M / R / C pick Metal, Roughness, Clearcoat. They do not change the paint colour, so a flat colour preview looks the same: judge them in the spec preview. The call REPLACES the existing spec stack, so send every layer you want to keep. Use them to weave a pattern's look into the shine without touching the colours.

## Controls: direct metal / roughness / clearcoat (spec shift)
SPEC SHIFT [spec_shift {metal, rough, clearcoat}, each -127..127] pushes the zone's Metal, Roughness and Clearcoat channels. Metal + = more metallic; rough + = duller, rough - = glossier; clearcoat: 16 is the maximum gloss and higher is duller, so clearcoat + dulls. Satin = rough +40..+80 and clearcoat +30..+60. These add on top of the finish, patterns and spec strength. There is no slider for absolute values: pick a finish whose card has the wanted shine, then shift.

## Controls: which pixels, order, mute (zone rules)
A zone owns pixels chosen by region: named part (left side, hood), band (height roof-line to rocker, length front to rear), layer, element (numbers / sponsors / stripes), colours with tolerance (6-100: "the blue parts"), exclude, or everything / remaining. WHERE TWO ZONES SELECT THE SAME PIXEL THE ONE HIGHER IN THE LIST WINS (lower index = top). New zones go on top. The "remaining" zone must stay last. MUTE hides a zone without deleting it. If a new zone shows nothing, a zone above has already claimed those pixels.

## Controls: the colour rules that trip people up
1) Items split into "takes the zone colour" (gloss, satin, matte, candy, pearl, metallic: a solid colour or gradient recolours them) and "brings its own colours" (monolithic specials, most pattern palettes, camo / snake finishes). Solid colour on an own-colour finish (measured) paints it one flat colour and loses the camo: shift its hue / saturation instead, or choose a take-colour base plus a pattern. 2) Hue shift is relative to what is there, not an absolute target: measure, then nudge by 10-20 degrees. 3) The helper never sets Color Lab depth. 4) Whole-car looks use the zone region everything + paintable; decals (numbers, sponsors) stay on top.

## Recipe: "pink camo rattlesnake" built from sliders when no such finish exists
1) Do not search for the exact phrase: split it. Camo = the look, pink = a colour, rattlesnake = a scale pattern. 2) Base zone (this is the pink): a base that takes colour (gloss, satin or matte), colour solid pink (#ff69b4 hot pink, #f4a6c0 soft) or, if you start from an existing green camo finish, hue shift about -150 (measured: green becomes hot pink) plus saturation +30 and brightness +40. 3) Camo on the same zone: pattern "multicam" (or "camo") with paint mode Blend so the pink base colour stays, opacity 70, scale 0.6. 4) Rattlesnake: the paint pattern "snake_skin_3" (hourglass viper saddles) as a second zone on top at opacity 40-60 and scale 0.5, or keep colour untouched and weave it into the shine with spec pattern "spec_snake_scales" at opacity 50-70, scale 0.4-0.6, channels MR. 5) Optional satin: spec shift rough +40, clearcoat +30. 6) Look at the preview, say plainly what was matched and what was approximated.
