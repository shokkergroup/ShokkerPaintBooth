## 1. 🚫 NON-NEGOTIABLE DOCTRINES (Ricky's rules — do NOT violate)

1. **NO DUPLICATION / unique identity.** Every finish/pattern/spec gets its OWN algorithm + identity. Never borrow/recycle/copy — learn ideas, build FRESH, always innovate. A rebuild/replace is a *new* thing, never a recolor. → memory `spb-spec-diversity-doctrine`.
2. **UV-ORIENTATION-AGNOSTIC.** The paint is a **2048×2048 UV map** and **every car lays panels out differently** (reversed/flipped/rotated/scattered). So **NO straight up-and-down anything** — no literal flags, no 13 parallel stripes, no canton grids, no centered upright emblems. Use **abstract / rotated / omnidirectional / radial / scattered / multi-angle** motifs.
