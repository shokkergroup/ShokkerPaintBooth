Vision — first-class pillar, not a bolt-on

SHOKK DROP is SPB's finish-from-any-art lane: drop a PNG/JPG/WebP (or a friend's pack), get a Viva-grade spec map via Import DNA, commit to your local library, and use the finish immediately in zones — same picker, same render pipeline, same Finish Viewer as shipped catalog finishes.

Shipped: Lab + DNA + packs + gallery Internal API: /api/user-imports Picker group: SHOKK DROP Next: in-booth drop zone + car preview

Cousin products

.SHOKKFull session — zones, layers, decals, baked paint/spec state. Heavy, complete design.
.spbdropLightweight finish pack — paint plate + spec + manifest. Share one finish, not a whole car.
SPB-71 Spec SculptFuture deep spec builder from existing livery paint. Complements Drop (art → spec) vs Sculpt (paint → spec).
Guest DesignerCurated drops merged into same picker family (Lyons Designs, etc.).

Gauntlet (quality gate)

  • Per channel: σ ≥ 20, range ≥ 150 on [0,255]
  • Up to 5 boost passes with escalating flake/line/metal/rough/clear deltas
  • Gallery + library show PASS/FAIL badge; aligns with SPB-105 / owner spec-channel doctrine
  • vibe_ref — optional shipped finish id to bias DNA personality

Owner mandate: fine 8–32px features at 2048², many distinct spec shades — DNA iterations must chase eye, not lazy macro blobs (see AGENTS.md).

Viva / Grunge logic — holes in the current stack

Import DNA calls build_cultural_viva_mexico.make_spec_plate(paint, …) with Grunge hooks swapped in. The plate is read for luma/hue/sat/edges — but creativity is still mostly procedural wallpaper keyed on filename + style id, not on what the image actually depicts.

What actually uses the paint plate today

Signal from paintUsed forLimitation
Luma, hue, sat, val, Sobel edge, Laplacian, blur bandsWeights in metal_energy / rough_energy / clear_energyGlobal fields — no “this blob is scales”
warm / cool from hueExtra metallic/clear on warm/cool regionsNot “electric red on dragon”; just warm bias
contour / trace from edgesRidge metallic + gloss corridorsAll edges treated similarly (+28 M in edge_lock)
Procedural x, y grids (2048²)Silk, ridges, spark, micro_mosaic at fixed frequenciesNot aligned to art geometry — 64px ridge on car = mirror-sized on body

What does NOT use the paint plate (critical gaps)

1. Name/style keyword routing

semantic_masks() and grunge_hidden_motif() branch on "{name} {style}" text — e.g. "calavera", "hexagon". User drops dragon_scales.png → name is dragon_scales, style is metal_flake → no scale motif path.

2. Classifier is global statistics @ 512²

classify_style_from_image sees edge density, saturation, halftone energy — not periodic scale texture, feather barbs, or segmented subject. Cannot pick “trace scales in electric red.”

3. Material hints are coarse buckets

carbon / chrome_holo / leather only nudge metal_base, flake, etc. — not per-region chromatic spec palettes.

4. Single-tier edge boost

edge_lock_spec_plate adds one corridor: +28 M, +22 CC on all edges. Owner wants 8+ distinct spec shades per feature — not uniform rim light.

5. micro_flake is paint-blind

Random 10px tile sparkles everywhere at 0.78 threshold — not “46 pink/orange/blue CC tiers on each scale cell.”

6. Gauntlet = contrast meter, not art fidelity

Passes when σ and range hit thresholds. A spec can PASS while ignoring dragon scales entirely (procedural noise fills the gap).

7. SHOKK THE WORLD = 10 recipes × remix

Twenty variants rotate personalities, not detected motifs. Same dragon might get acid_wash turbo #17 with no scale tracing.

Paint-aware DNA — proposals (dragon scales example)

Goal: Trace elements that exist in the art; fill smartly; let which colors/styles vary per DNA style / World variant — e.g. scales outlined in electric red metallic with 46 distinct CC/M tiers per cell for wild sun-angle shimmer.

Track A — Motif detection layer (recommended first)

New module engine/paint_v2/import_paint_motifs.py runs before bake, outputs masks @ 2048:

DetectorMaskDragon scales use
Multi-scale edge + periodicity (FFT/autocorr on 8–32px bands)scale_latticeHex/scale repetition → trace each cell boundary
Closed contour / watershed on edgeregion_cellsPer-scale ID for per-cell palettes
High-frequency Laplacian peaksfine_detailMicro sparkle only on texture, not flat fill
Hue clustering (k=6–12)chroma_zone_*Red body vs gold trim → different spec stories
Subject silhouette (alpha or saliency)subjectBackground stays matte; dragon gets spec love

Track B — Chroma spec paint (the “46 shades” engine)

Replace uniform edge boost with quantized palette stamping per mask ID:

  • Build tier list per style: M_tiers = [0.18, 0.28, …, 0.92] × style accent (electric red → M biased high on R channel of spec preview, but stored as M value variety)
  • For each scale cell i: M[i] = M_tiers[hash(i, seed) % 8], CC[i] = CC_tiers[…] with hue-dependent tint from paint chroma at cell centroid (pink/orange/blue shifts in CC and secondary M bumps)
  • Angle story: alternate tiers on checkerboard or along scale direction so sun sweep changes which cells flash — reads as iridescent on car

Track E — Post passes that respect regions

  • edge_lock_v2: per-edge tier from local paint hue + style accent color (red dragon → M 200–255 on rim, G 40–90 in groove)
  • micro_flake_v2: sparkle only where fine_detail ∧ subject; tier CC from 8-color palette per cell
  • void_flatten: borrow Viva _post_adjust — dark non-edge interiors → kill stray metallic (already in masterclass)

Dragon scales — target read in sim

TraceScale boundaries = high M ridge (~12px), style accent hue bias (electric red)
FillEach cell = pseudo-random tier from 8 M + 8 CC + 6 R palettes tied to paint color under cell
MotionNeighboring cells differ tier → sun angle changes which scales “light up”
BackgroundOutside subject mask → low M, high R (matte void)

Suggested build order (SPB-109 / SPB-71)

  1. Motif masks + debug overlay in Shokk Drop preview (toggle lattice/cells)
  2. chroma_spec_stamp() post-pass on baked spec (fast win before rewriting make_spec_plate)
  3. scale_armor_trace style + World planner hook
  4. image-driven hidden_motif inside Import DNA bake path
  5. Deep refactor: pass motif_masks into make_spec_plate (shared with Spec Sculpt)

Reference doctrine: VIVA_MEXICO_SPEC_PIPELINE_MASTERCLASS.md §5 — triplet variation + paint-ground-truth masks (already proven on shipped cultural finishes; Import DNA never got the full mask graph).

Why it still feels like a bolt-on

Separation anxiety

Primary UX lives on a separate page/window. Paint Booth treats it as a header button, not a phase of the paint workflow (compare: loading source paint → zones → finishes).

No "drop on car" moment

Users commit in the Lab, then context-switch to booth to apply. Missing: drag art onto canvas OR current livery → preview on car → one-click apply to active zone.

Quality story is invisible in booth

Gauntlet PASS/FAIL only in Lab gallery. Picker swatches don't telegraph spec richness or M7 score.

Spec Sculpt (SPB-71) not linked

Two spec-creation stories without bridge: Drop (external art) vs Sculpt (existing livery). Should feel like one "Spec Workshop" family.

Naming split brain

User-facing: SHOKK DROP. Code: user_imports everywhere. Fine for devs, confusing in docs/tickets without this bible.

Roadmap — make it REALLY cool

P0 — Feel native in Paint Booth (1–2 sessions)

  • In-booth Drop strip — collapsible right-rail or bottom dock: mini gallery of last 8 drops + drag PNG → preview without leaving booth
  • Apply to active zone — one click from preview: set monolithic finish on selected zone + trigger live preview
  • Gauntlet chip in picker — ✓/! on swatch tooltip with M/R/C σ summary
  • Link Lab ↔ booth state — deep link ?apply=ui_foo&zone=2 after commit
  • Rename trail — inline edit display name in gallery + library (manifest patch)

P1 — Social & creative power

  • Drop Collections — user-defined folders (Race Night, Neon Pack) + filter in gallery
  • Batch inbox — polish process-inbox UX: folder watch, batch DNA with progress bar
  • Before/after car reel — use car preview: Trading Paints livery → apply drop → side-by-side export PNG
  • DNA remix slider — blend two styles or vibe_ref A↔B interactively before commit
  • Community hash — optional short code on export (like share id) for Discord/forum drops
  • Compare mode — select 2 gallery cards → split spec channel diff view

P2 — Pro quality & workshop integration

  • M7 on commit — auto-run workbook for paint drops; block commit if <85 unless owner override
  • Upgrade to .SHOKK — "Package as full design" from current booth session + active drop spec
  • Spec Workshop hub — unified nav: SHOKK DROP | Spec Sculpt (SPB-71) | Import Spec Map
  • AI brief field — one-line prompt stored in manifest; future style routing
  • Reference texture attach — optional PNG alongside DNA for hybrid Viva-style enhancement
  • Trading Paints import — paste TP id → pull livery → Drop DNA on it (Spectrum Shift pitch)

P3 — Platform & monetization-ready

  • Guest Designer pipeline — signed packs, verified badge, featured carousel in Lab
  • Drop Store stub — browse remote packs (CDN manifest) — local import only at first
  • Versioned pack schema v2 — thumbnails, tags, author, min SPB version
  • Collaboration — export pack with edit notes; import merges with conflict UI

5-minute sell demo

  1. Generate art externally (Midjourney, Photoshop, etc.)
  2. Open Shokk Drop (header or Ctrl+Shift+D) → drag PNG to sidebar → Import & preview
  3. Review upload + spec ALL + R/G/B panels → note gauntlet PASS → Commit drop
  4. Click gallery card → Pipeline render thumb → Copy link for friend
  5. Paint Booth → load livery → Specials → SHOKK DROP → apply to zone → Full Render
  6. Finish Viewer → drop shows human name, not ui_slug
