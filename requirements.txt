# WHY EXACT PINS (== not >=):
#   The render engine performs deterministic floating-point math (procedural
#   noise fields, scipy filters, numpy array ops) whose output is part of the
#   SHIPPED PRODUCT. A silent transitive bump of numpy or scipy can shift
#   rounding, change filter kernels, or alter RNG behavior and thereby change
#   finish output pixel-for-pixel. Pinning the EXACT versions validated on the
#   known-good build machine protects the engine math from this kind of
#   invisible drift between fresh clones and CI runs.
#
#   These versions are the ones ACTUALLY INSTALLED & validated in the known-good
#   environment (captured via `pip freeze`; Python 3.13.5, pip 25.1.1). The full
#   resolved environment - including every transitive dep - is recorded in
#   requirements.lock alongside this file.
#
# This file is a runnable SUPERSET of pyproject.toml [project].dependencies:
# it is the curated set of DIRECT project deps needed to run the engine + the
# Flask server from a clean clone. (Historically this file was missing
# noise/opencv/requests/colorama, which produced a non-runnable engine -
# ImportError on `noise`.)
#
# BUMP PROCEDURE: change a pin here intentionally, re-run the engine test
# suite + visual-diff harness, then regenerate the lock:
#   python -m pip freeze > requirements.lock
# -----------------------------------------------------------------------------
