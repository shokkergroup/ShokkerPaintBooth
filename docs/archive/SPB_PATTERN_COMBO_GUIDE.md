# SPB Pattern + Base Combo Guide

> Finishes are the vocabulary. Patterns are the grammar. This guide lists 30+ proven combinations, describes *why* they work, and flags combos to actively avoid.

Every combo below assumes the pattern is applied to at least one panel but does not need to cover the whole car.

---

## Section A — The Top 30 Proven Combos

- **Base:** `gloss_wrap` (any color, usually black, navy, or white)
- **Pattern:** `carbon_weave`
- **Where to apply pattern:** Hood, roof, mirror caps.
- **Visual effect:** Functional-sport vocabulary. The car reads as "modern performance" immediately.
- **Ideal vibe:** Modern sports coupe, GT3, contemporary racer.
- **Difficulty:** Beginner.

## Section B — Combos to AVOID

| Base | Pattern | Why to avoid |
|------|---------|--------------|
| `chrome_wrap` | Rust / patina overlay | Reads broken, not weathered. Chrome implies care. |
| `matte_wrap` | High-gloss spec overlay in same color | Spec fights the finish; looks like a rendering bug. |
| `candy_apple` | `candy_burgundy` stripe | Two candies = muddy seam. Pick one jewel. |
| `carbon_weave` | Carbon-weave accent | Pattern redundancy. Nothing reads. |
| `gloss_wrap` hot pink | `neon_underground` hot pink grid | Neon on neon = illegible. Dark base required. |
| `chameleon_base` | Heavy chrome_wrap everywhere | Chrome competes with the shift. Pick one spectacle. |
| `pearl_base` white | Plaid in pastel colors | Delicate + delicate = invisible. Need value contrast. |
| `matte_wrap` camo | Candy accent stripes | Mixes utility vocabulary with jewel vocabulary. Pick one. |
| Any glossy base | `damage_wear_v2` at 40%+ | Gloss + damage reads fake/prop. Keep damage to matte. |
| `gloss_wrap` saturated primary | Full carbon weave body | Loud + technical cancels both vocabularies. |

## Section C — Layering Patterns (Advanced)

Sometimes you want two patterns on one car. Follow these rules or suffer.

### Rule 1 — Different panels, not the same panel.
Pattern A on the roof, Pattern B on the rockers. Never both on the hood.

### Rule 2 — Value hierarchy.
The primary pattern should be higher contrast. The secondary pattern should be a whisper.

### Rule 3 — Matched vocabulary.
Both patterns should come from the same "world":
- Carbon + hex grid = engineering
- Plaid + pinstripe = heritage
- Camo + damage overlay = field-use

Mixing worlds (camo + plaid) only works as irony or as a very deliberate thesis statement.

### Rule 4 — 70/30 coverage max.
Patterns combined should never exceed 70% of body surface. Leave 30%+ as clean body for the eye to rest.

### Rule 5 — One pattern per color zone.
Don't run two patterns across the same color. Change the color when you change the pattern.

### Rule 6 — Direction matters.
If both patterns have a direction (stripes, weaves, chevrons), align them or aggressively contrast them. Never leave them at an awkward 15° mismatch.

## Section E — Tips From the Lab

- **Always preview the pattern at full zoom AND at thumbnail distance.** What looks great at 1:1 may vanish at arms-length.
- **Pattern strength is 70% of the quality.** The same carbon_weave at 40% vs 90% strength is an entirely different look.
- **Patterns on curved panels distort.** Avoid geometric patterns (checkers, hex) on highly curved fenders unless distortion is the design.
- **Pattern scale matters more than color.** A small-scale plaid reads luxury; a large-scale plaid reads picnic blanket.
- **Never pattern the glass area.** Keep patterns clear of window openings for cleanliness.

## Final Word

Patterns are power tools. They finish a design or destroy it — rarely anywhere in between. When in doubt, use one pattern well rather than three patterns half-heartedly.
