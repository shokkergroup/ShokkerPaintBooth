HOW IT WORKS
Two ways to tell the engine which pixels belong to each zone:
🎨 PICK COLOR — Best for body paint (large solid areas)
Click a body color on the paint → assign to zone → engine finds all matching pixels
🖌️ DRAW REGION — Best for numbers, sponsors, artwork
Select a zone → switch to Draw Region or Rectangle → paint over the area on the UV map
All drawn pixels get the same finish regardless of their color
🎯 MAGIC WAND — Smart select for numbers, logos, shapes
Click on a number or logo → auto-selects all connected pixels of similar color
Shift+click to add more areas. Adjust tolerance slider for tighter/wider selection. Ctrl+Z to undo.
WORKFLOW:
1. Load paint image → 2. Body colors: Pick Color mode, click each body color → 3. Numbers/logos: Magic Wand to auto-select, or Draw Region to paint manually → 4. Assign finishes → 5. Generate Script
TIP: Delete zones you don't need (X button). Custom Art slots are for special elements like a logo S that deserves its own holographic finish. PRIORITY: Zone 1 claims pixels first. Later zones get what's left. Drawn regions ALWAYS win over color picks.

iRacing SIM-STAMP MATERIAL FIX

                    
Decal Rescue Kit

                

                
            

            

                
Sim-stamped numbers and sponsors inherit the spec map underneath them. Pick the active Zone selection's safe material so white vinyl stays readable over chrome, candy, or metallic bodywork.

                
Active Zone selection

                

                

                    
                    
                    
                

                

                    Workflow: draw the underlying number/sponsor footprint with Rectangle, Lasso, Pen, or Smart Region. Use Mask › Grow first if the stamp needs edge safety. This action changes only the active Zone's material recipe; it preserves the selection, source paint colors, and all PSD layer pixels. Spatial matching and PSD-layer restriction are cleared so the exact UV footprint is authoritative. One Undo restores the prior Zone recipe.

iRacing SPEC ALPHA CONTROL

                    
Lighting Mask

                

                
            

            

                
Control how much sun, reflection, and environment lighting reaches the exact active Zone selection. This edits only the exported spec TGA alpha channel—it does not change paint RGB or the Metallic, Roughness, and Clearcoat channels.

                
Active Zone selection

                
Use zero carefully: Kill Lighting is for fake holes, grille openings, and geometry that should appear unlit. It is not a shortcut for matte vinyl.

                

                    
                    
                    
                    
                

                

                    Workflow: draw the UV footprint with Pen, Lasso, Rectangle, or Smart Region; refine it from the Mask menu; then choose the lighting response. Soft selection edges produce a soft alpha transition. One Undo restores the previous Zone alpha setting.
                

            

            

                Spec alpha only • exact Zone footprint • M/R/CC preserved
                
            

        

    


    
    

        

            

                

                    
TEXTURE-PRESERVING iRACING SPEC LEVELS

                    
Material Range Remapper

                

                
            

            

                
Compress each generated or imported material channel into a new output range while retaining its scratches, weave, flake, and wear. The active Zone selection owns the exact UV footprint.
