## Lessons for both assistants

1. Verify facts under the exact vehicle heading in a release note. Search snippets can attach a neighboring car's update to the wrong model.
2. A shared ZIP or paint folder does not mean a shared applicable PSD. Gen4 standard and superspeedway files must remain separate; deduplicate by car and document, not archive alone.
3. Group names vary. Examples include `Paintable Area`, `Body Paint`, `Color Change`, `Custom Spec Map`, `Spec`, and `Custom Spec`. A familiar word can label either paint or a spec-channel mask.
4. Layer names and bounding boxes do not prove UV orientation or an actionable panel mask. Tiny control pixels, forced decals and alpha channels need protection based on the real file.
5. A filename can omit an updated model name such as Evo. Bind the inspected content and version evidence, not just a friendly filename.
6. Distinguish template revisions, paint-pattern changes, model artwork, garage options and simulator rendering fixes. A windshield rendering fix does not prove a revised PSD.
7. Test answer content, not just the winning article. The right car with the wrong FAQ still fails the customer's question.
8. First-message loading must finish before concluding that an offline answer is missing.
