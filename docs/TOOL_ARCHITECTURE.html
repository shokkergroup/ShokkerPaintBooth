No architectural boundary exists between Zone tools and Layer/PSD tools. Only a runtime flag + giant closure. This is why tools still feel jinky compared to Photoshop, GIMP, or Trading Paints.

The Fundamental Split

Zone System Traditional
  • Operates on zones[i].regionMask + spatialMask
  • Classic SPB workflow (zones + finishes)
  • Tools: Brush, Wand, Rect, Lasso, Spatial, Pen, Selection Move
  • Undo via pushZoneUndo
Layer / PSD System Newer
  • Operates on active PSD layer pixel buffers + transforms
  • Activated when PSD imported (_psdLayersLoaded)
  • Tools: Clone, Color Brush, Smudge, History Brush, Dodge, Burn, Text, Shape
  • Undo via _pushLayerUndo + layer snapshot
The goal: Make both sides feel equally premium and trustworthy

The Zone / Layer Contract — Hard Rules

1. Ownership is Absolute

Zone code only touches zone masks. Layer code only touches PSD layer pixels. No exceptions.

2. Dispatch is the Single Source of Truth

Only dispatch.js (or the dispatch section) decides routing using the two guard maps and isLayerToolbarMode().

3. No Cross-Contamination

A Zone-only tool must never write to layer pixels. A Layer-only tool must never write to region/spatial masks.
