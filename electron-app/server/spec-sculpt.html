FRACTURE ignition

Ignites the loaded paint with the FRACTURED look: a near-chrome body (Metallic ~252) under a maxed clearcoat (~255) that flares at grazing angles, with the paint's own geometry traced as a woven roughness motif. Paint stays untouched; only the spec is sculpted.

Calm floor 30

Decorrelation 0.00
Pushes Metallic / Roughness / Clearcoat motifs apart so the channels aren't carbon copies (0–1).
CANDY DEPTH

Sculpts a bottomless WET-CANDY clearcoat from the loaded paint: rich/dark areas become deep glassy candy (max clearcoat + wet gloss), pale areas stay thin satin, and metallic flakes are suspended so they read THROUGH the coat. Paint stays untouched; only the spec is sculpted.

Pipeline DNA (Viva / Rising Sun / Union Jacked): Spec Sculpt runs the same catalog-wide _pre_adjust_viva_mexico_spec pass documented in VIVA_MEXICO_SPEC_PIPELINE_MASTERCLASS.md (ridge relief, chromatic triplets, sparkle grids, nano, void-safe post). Procedural detail intensity (DS) 1.59
~1.59 matches shipped Viva defaults; higher pushes ridge/dot/nano harder (watch metallic clipping). Lower calms busy skins.
Advanced material tuning Advanced

Order on the car: (1) big procedural pass + DS → (2) Interior flatten feeds the VM pre-pass → (3) Spec strength scales metallic after that → (4) Void * runs last on “empty / dark paint” pixels only so poster fields don’t look chrome.

Interior 38% · spec 100% · void M≤92 · R≥158 · Cc≤44
Interior flatten 38%
When: during VM _pre_adjust, not at export. Effect: where paint is dark and low-detail (interiors / big ink fields), blends spec toward matte so those zones don’t bloom metallic. Higher = more “flatten” in those pockets (safer on navy/text-heavy skins).
Spec strength 100%
When: after pre-adjust, before post. Effect: multiplies the metallic channel (and ties to mask): global “how strong metal reads.” Lower = duller metal everywhere; 0% kills metal signal.
Void metallic cap 92 (0–255)
When: _post_adjust, only pixels flagged “void” (dark diffuse, not ridge-protected). Effect: metallic on those pixels cannot exceed this value — kills fake chrome in empty panels. Lower = flatter voids.
Void roughness floor 158 (0–255)
When: same void mask as above. In this repo, higher roughness = duller. Effect: void pixels get roughness at least this high → more matte in dead areas. Higher = rougher voids.
Void clearcoat cap 44 (0–255)
When: same void pass. Effect: clearcoat on void pixels cannot exceed this — caps gloss in empty regions. Lower = less sheen in voids.
