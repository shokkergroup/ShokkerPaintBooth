## Universal logo sourcing mandate — owner, 2026-09-12

Applies to EVERY car design and every sponsor identity, not only Quiksilver.

- Search the owner's master Logos folder and FORGE PROJECT/LOGO LIBRARY first. An existing low-quality file is not a reason to stop looking.
- If a suitable high-quality original is absent, ALWAYS search the web for the best available clean source. Prefer original brand vector artwork (SVG/EPS/AI/PDF with real curves), official brand/media resources, then reputable source libraries or sufficiently sharp original raster assets. Inspect identity, spelling, contours, transparency and actual placement-size legibility; filename, pixel count or an upscale alone proves none of these.
- If usable clean sources cannot be found, faithfully reconstruct the best available reference at production quality, preferably editable vector curves. Retain exact mark geometry, lettering, proportions and the owner's hand gesture. Do not substitute approximate generated logos or guessed typography. Record reconstructed status and compare with the source before use.
- Recolor to suit the scheme and add coordinated strokes/keylines where needed for contrast, preserving identity and aspect ratio. Check the logo on its actual body-panel background.
- Save selected originals and reusable derivatives into the logo library with source URL/path, provenance, dimensions/vector status, hashes and a quality-review note. Reuse the verified best source on later cars; do not repeatedly download, redraw or upscale an already suitable asset.
- Keep every logo separate from complete underlying artwork in Detailed/8/3-layer PSD deliveries. Concept-render crops and blurry logos are not production shortcuts when cleaner originals or faithful reconstruction are possible.
