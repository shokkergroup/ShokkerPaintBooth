# Shokker Paint Booth 10.0.3

10.0.3 fixes the Base Material color-mode problem affecting Fractured, Shokker, Cultural, gradients and other finish collections.

- **Use Source Paint (Spec Only)** keeps your existing paint while applying the finish's material properties.
- **Use Finish's Own Color** applies the finish's paint design when it has one. Switching back restores the source paint.
- Gradient finishes now preserve the original paint correctly when changing color mode or Base Strength.
- Color-mode choices stay consistent through preview, Render, Photoshop export and saved projects.

This update includes the Pattern Hue, Saturation and Spec Amount controls, Spec Overlays v2 and SHOKK DROPS features delivered in 10.0.2.
